# FarukSamiBilgin.github.io

Source of https://faruksamibilgin.github.io — *Notes on quantum devices*: seven short chapters on twisted lattices, Josephson junctions, qubits, coherence and quantum repeaters.

A single static page (HTML, CSS and plain JavaScript; KaTeX for equations; no build step). Figures 1–4 are computed in the browser from the equations beside them: the moiré period L = a / 2 sin(θ/2); the short-junction current–phase relation; an overdamped RSJ junction under microwave drive (Shapiro steps); and the Cooper-pair-box Hamiltonian diagonalised in the charge basis by Sturm bisection. Figures 5–6 and the panel figures are loaded unchanged from the linked research repositories.
